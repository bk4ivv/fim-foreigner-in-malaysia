# FIM - Foreigner in Malaysia 🇲🇾

A comprehensive utility application built with Flutter, designed to assist expats, foreign workers, and international students living in Malaysia.

## 📱 About the Project
**FIM** provides essential resources, status checking tools, and daily life guides to make navigating life in Malaysia easier and more accessible.

## ✨ Features
* **Status Checker:** Quickly check relevant expat and visa statuses.
* **Daily Guides:** Access vital information about living, working, and studying in Malaysia.
* **Resource Hub:** Find important emergency contacts and local services.

## 🛠️ Built With
* [Flutter](https://flutter.dev/) - UI Toolkit
* Dart - Programming Language
